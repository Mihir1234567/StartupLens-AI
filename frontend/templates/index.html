⚙️ Machine Learning Pipeline Architecture

Target Variable: Continuous funding amount transformed via natural log scaling: y = log(1 + Amount_USD)

Categorical Encoder: Scikit-Learn OneHotEncoder(handle_unknown='ignore') preserving inference stability on out-of-distribution inputs.

Continuous Preprocessor: StandardScaler coupled with SimpleImputer(strategy='median').

Tuned Estimator: GradientBoostingRegressor(n_estimators=150, learning_rate=0.08, max_depth=4).

Serialization: End-to-end composite pipeline pickled via joblib into startup_funding_predictor.joblib.
